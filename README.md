# Trendy Shop

Proyecto de e-commerce desarrollado como parte de la formación en Generation Colombia.

## Estructura del proyecto

```
trendy-shop/
├── assets/
│   └── images/
│       └── productos/    # Imágenes de productos
├── src/
│   ├── index.html        # Página principal
│   ├── catalogo/         # Módulo: catálogo de productos
│   ├── quienes-somos/    # Módulo: información de la empresa
│   ├── contactanos/      # Módulo: formulario de contacto
│   └── carrito/          # Módulo: carrito de compras
└── README.md
```

## Módulos

| Módulo | Descripción |
|--------|-------------|
| `index` | Página principal / landing |
| `catalogo` | Listado de productos disponibles |
| `quienes-somos` | Información sobre la empresa |
| `contactanos` | Formulario de contacto |
| `carrito` | Carrito de compras |

## Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)

## Cómo ejecutar

Abre `src/index.html` en tu navegador, o usa un servidor local:

```bash
npx serve src
```
